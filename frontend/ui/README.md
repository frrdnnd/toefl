# SMARTTOEFL AI Frontend

Vue 3 + Vite frontend for SMARTTOEFL AI.

## Setup

```powershell
npm install
copy .env.example .env
npm run dev
```

Default backend URL:

```env
VITE_API_URL=http://127.0.0.1:8000
```

See the root `README.md` for full backend, Ollama, RAG, and troubleshooting instructions.
